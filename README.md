## 🛡️ Recommended Security Practices

* **Bytecode Obfuscation & Virtualization:** Java bytecode (.class files) can be easily reversed using tools like CFR, Procyon, Fernflower, or JD-GUI. For production releases, protect compiled classes and JARs using commercial obfuscators such as **Zelix KlassMaster (ZKM)**, **ProGuard**, or **DexGuard** to encrypt string literals, rename symbols, and flatten control flow.
* **Ahead-Of-Time (AOT) Native Compilation:** Compile Java code into standalone native executables (.exe on Windows, ELF on Linux) using **GraalVM Native Image** (`native-image -jar MyApp.jar`). This strips JVM bytecode entirely and eliminates conventional decompilers.
* **Memory Buffer Sanitization:** Clear sensitive credentials, decrypted tokens, and cryptographic keys immediately after use by zeroing arrays (`Arrays.fill(bytes, (byte) 0)`).
* **In-Memory Secure File Execution:** When retrieving protected binary modules or JAR assets with `NightAuthApp.downloadFile()`, **never write bytes to physical storage or disk**. Load bytecode directly into memory via custom in-memory `ClassLoader` implementations (`defineClass`) and purge temporary buffers immediately.

## 📦 Requirements & Building

Requires **JDK 17** or later (tested on OpenJDK 17, 21, and 25 LTS). Zero external dependencies — built exclusively with standard JDK libraries (`java.net.http`, `javax.crypto`, `java.security`).

### Build & Run Console Client
```bash
# Compile SDK and Console
javac -d build sdk/src/main/java/com/nightauth/sdk/NightAuthApi.java console/src/main/java/com/nightauth/console/Main.java

# Run Console
java -cp build com.nightauth.console.Main
```

### Build & Run Desktop Client (Swing GUI)
```bash
# Compile SDK and Desktop
javac -d build sdk/src/main/java/com/nightauth/sdk/NightAuthApi.java desktop/Main.java

# Run Desktop
java -cp build com.nightauth.desktop.Main
```

### Package Standalone Executable JARs
```bash
# Build Console JAR
jar cfe NightAuth-Console.jar com.nightauth.console.Main -C build .

# Build Desktop JAR
jar cfe NightAuth-Desktop.jar com.nightauth.desktop.Main -C build .
```

## ⚙️ Configuration & Initialization

Define your application credentials from the **Manage Apps** tab of the NightAuth dashboard:

```java
import com.nightauth.sdk.NightAuthApi;

public static final String APP_NAME = "";
public static final String APP_API_KEY = "";
public static final String APP_VERSION = "1.0";
public static final String APP_TOKEN = "";

public static NightAuthApi NightAuthApp = new NightAuthApi(
    APP_NAME,
    APP_API_KEY,
    APP_VERSION,
    APP_TOKEN
);
```

### Initialize Cryptographic Handshake (`init`)

You must call `init()` prior to executing any other SDK functions. This establishes an ephemeral Diffie-Hellman (X25519) key exchange and an encrypted session:

```java
NightAuthApp.init();

if (!NightAuthApp.response.success) {
    System.err.printf("Initialization failed: %s\n", NightAuthApp.response.message);
    System.exit(1);
}
```

## 🚀 SDK Usage Guide

### 1. Check Session Validation & Blacklist Status

```java
// Validate active session status with the server
if (!NightAuthApp.check()) {
    System.out.printf("Session invalid: %s\n", NightAuthApp.response.message);
}

// Check if client HWID or IP address is blacklisted
String hwid = NightAuthApi.getHardwareId();
if (NightAuthApp.checkBlacklist(hwid)) {
    System.err.println("Access Denied: Machine or IP is blacklisted.");
    System.exit(1);
}
```

### 2. Login with Username & Password (and 2FA)

```java
if (NightAuthApp.login(username, password, totpCode)) {
    System.out.printf("Welcome back, %s!\n", NightAuthApp.user.username);
} else {
    System.err.printf("Login failed: %s\n", NightAuthApp.response.message);
}
```

### 3. Register with License Key

```java
if (NightAuthApp.register(username, password, licenseKey, email)) {
    System.out.printf("Registration successful: %s!\n", NightAuthApp.user.username);
} else {
    System.err.printf("Registration failed: %s\n", NightAuthApp.response.message);
}
```

### 4. Authenticate with License Key Only (and 2FA)

```java
// Authenticate using license key alone or with 2FA TOTP code
if (NightAuthApp.license(licenseKey, totpCode)) {
    System.out.printf("License valid! Logged in as: %s\n", NightAuthApp.user.username);
} else {
    System.err.printf("License authentication failed: %s\n", NightAuthApp.response.message);
}
```

### 5. Upgrade Account / Claim License Key

```java
if (NightAuthApp.upgrade(username, licenseKey)) {

} else {
    System.err.printf("Upgrade failed: %s\n", NightAuthApp.response.message);
```

### 6. Reset Hardware ID (HWID Lock)

## 🆚 Why NightAuth? (KeyAuth & Auth.gg Comparison)

| Feature | NightAuth | KeyAuth | Auth.gg |
| :--- | :---: | :---: | :---: |
| **Cryptography** | **End-to-End Curve25519 (X25519) + ChaCha20-Poly1305** | Static AES-CBC (Vulnerable to MITM & Proxy Interception) | Legacy HTTPS / Plain JSON |
| **Hardware ID (HWID)** | **Multi-Component Cryptographic Hash (Anti-Spoofing)** | Raw WMI Strings (Trivially Spoofed) | Simple Registry / MAC |
| **Edge Network Latency** | **< 35ms Global Anycast Edge Network** | Single-Origin VPS (Frequent Network Outages) | Unmaintained / High Latency |
| **Reseller System & Bots** | **Built-in Multi-Tier Credit Balances + Discord & Telegram Bots** | Manual API / Third-Party Scripts | Incomplete / Deprecated |
| **In-Memory Streaming** | **Zero-Disk Decryption with Direct Memory Execution & Buffer Wiping** | Disk Writes Required | Not Supported |
| **Internationalization** | **10 Languages Supported Out of the Box across Documentation & SDKs** | English Only | English Only |
